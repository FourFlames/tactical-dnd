# Pending library commands

Proposed engine commands wait here until JD reviews them and you approve.

- The DM writes proposals here as `<name>.js`, using `ext/shove.js` as the template.
- JD reviews (and may fix) them, then stamps `APPROVED` or `DENIED`.
- Only you decide whether a stamped command moves to `ext/`, where `node engine.js <name>` picks it up automatically.
